# Story 1.5: Continuous Deployment Setup

## Status
Draft

## Story
**As a** developer,
**I want** to set up continuous deployment for the application on Vercel,
**so that** any changes pushed to the main branch are automatically deployed.

## Acceptance Criteria
1. The monorepo is connected to a Vercel project.
2. Vercel is configured to correctly build and deploy the frontend application from the `ifx-app` directory.
3. Vercel is configured to correctly build and deploy the backend Docker container from the `app` directory.
4. A successful push to the `main` branch triggers a new deployment on Vercel.
5. The deployed application is accessible via a public Vercel URL.

## Tasks / Subtasks
- [ ] Task 1: Connect the GitHub repository to a new Vercel project. (AC: 1)
- [ ] Task 2: Configure the Vercel project to correctly identify the frontend application in the `ifx-app` directory. (AC: 2)
- [ ] Task 3: Configure the Vercel project to build and deploy the frontend application. (AC: 2)
- [ ] Task 4: Configure the Vercel project to use the backend Docker container from the `app` directory. (AC: 3)
- [ ] Task 5: Set up the necessary build and deployment settings on Vercel for the backend. (AC: 3)
- [ ] Task 6: Push a change to the `main` branch to trigger a deployment. (AC: 4)
- [ ] Task 7: Verify that the deployment was successful and the application is accessible via a public Vercel URL. (AC: 5)
