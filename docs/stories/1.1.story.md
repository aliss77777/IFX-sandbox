### Testing
- All unit and integration tests must use the `pytest` framework for the backend. [Source: docs/architecture/15-coding-standards.md]

- Assertions should include helpful error messages for easier debugging. [Source: docs/architecture/15-coding-standards.md]

### Source Tree
- The project is organized as a monorepo. [Source: docs/architecture/16-source-tree.md]
- `/app`: Contains the backend Python application, built with FastAPI. [Source: docs/architecture/16-source-tree.md]
- `/ifx-app`: Contains the frontend React application, built with Vite. [Source: docs/architecture/16-source-tree.md]
- `/docs`: Contains all project documentation. [Source: docs/architecture/16-source-tree.md]
- `/data`: Contains data for the fictional Huge League. [Source: docs/architecture/16-source-tree.md]
- `/tests`: Contains tests for the application. [Source: docs/architecture/16-source-tree.md]

### Tech Stack
- **Backend:** Python 3.13, FastAPI, Poetry, Docker. [Source: docs/architecture/14-tech-stack.md]
- **Frontend:** JavaScript/TypeScript, React, Vite, shadcn/ui. [Source: docs/architecture/14-tech-stack.md]
- **Development:** GeminiCLI, GitHub, Vercel. [Source: docs/architecture/14-tech-stack.md]
